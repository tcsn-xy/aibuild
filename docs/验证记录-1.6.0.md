## 边界

只支持已有26.3世界与一个本机玩家。后台是唯一存档写入者，客户端通过127.0.0.1加入；不支持外网/LAN访客加入后台模式。原普通单人/LAN桥接保持。

后端依原Minecraft加载和保存玩家数据；验证覆盖原UUID、物品数量及自定义名称，没有逐个验证所有第三方玩家组件。所有红石机器、长期无人运行和强杀/断电一致性未新增验证。1.5.2的完整投影/搬迁验收为历史记录，不冒称本轮重新跑过全部51项。

部分客户端模组按服务器连接组织地图缓存；已有单人地图文件保留。后台运行期间世界时间继续。无人游玩且任务结束时可以保存停止，有人游玩或正在加入时拒绝停止。

## 构建与使用

```sh
./build.sh
python3 scripts/offline.py worlds
python3 scripts/offline.py start "示例世界"
python3 scripts/offline.py status
python3 scripts/offline.py stop
```

之后仍使用workflow.py准备、检查、施工与回滚。用户无需开游戏或connect；中途在单人列表选择同一世界即可游玩。后台功能不改变已授权建筑范围；必须先读取当前现场再改世界。
